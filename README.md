Reincarnation Idle

Reincarnation Idle is an incremental idle game mixed with RPG. 
This will guide you on the installations of the game.

----------------------------------------------------------------------------------
Installation:
Follow these steps to download and run Reincarnation Idle in your
browser.

Prerequisites:
Before beginning, make sure you have an IDE (Integrated Development Environment).
For example, you can use Visual Studio Code.
Make sure an extension like vscode-live-server is installed to
run a server that can host the game locally.

Download the zip file.
Extract it.
Open the index.html file on the live server extension.

All images and sound used are sourced free from the internet with
permission to use. Spritesheets used are sourced from itch.io with permission.
